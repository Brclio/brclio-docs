# Skinny 话费充值教程

入口为 `index.html`，保持 `guide.css`、`guide.js` 和 `assets/` 的相对位置，可直接在现代浏览器打开。字体从 Google Fonts 加载；离线时回退到系统字体，正文和本地截图仍可阅读。

## 内容与交互

- 面向中文新手，适用于已激活的 Skinny Mobile 预付费手机卡。
- 五章：准备与银行卡要求、官网一次性充值、到账核对、App / 充值券 / 自动充值、常见问题。
- 包含 10 张截图：4 张官方公开页面 PNG、5 张用户提供的原始 PNG、1 张已登录 Chrome 补拍的银行卡填写页 JPEG；可切换适应窗口和 100% 原始尺寸、打开原图或下载。
- 目录与来源链接自动展开对应折叠内容；提供 BAL 指令复制、四项人工核对清单、进度保存和重置、打印样式。
- 清单仅记录读者的人工确认，保存在当前浏览器，不会检测 Skinny 账户、余额或付款结果。
- 知识库首页新增第 06 项，首页静态计数、搜索筛选和 JSON-LD 已同步；`sitemap.xml` 增加新路径。

## 事实与截图边界

核验日期：2026-09-09。全部引用指向 Skinny 官方来源，详细依据及资料冲突见 `SOURCES.md`。

- 实测未登录访问官网 Quick Top-Up 会跳转至 Skinny 登录页。一次性充值不等于免登录。
- 官方限制海外银行发行的卡；不能仅凭 Visa / Mastercard 标志判断可用。
- 充值余额与套餐购买 / 续订分别解释。Auto Top-Up 与 Set & Forget 也分别说明。
- 采用 2026-08-11 更新的条款：至少每 12 个月充值或续订套餐一次。
- 在用户已登录的 Chrome 中核对充值页面，选择 NZ$5 演示金额并点击 CONFIRM，确认下一页为银行卡填写页；没有填写或保存银行卡、点击 PAY。截图完成后返回原充值页，金额恢复为 $0。没有充值成功截图，未验证中国网络访问、银行验证、漫游短信和实际到账。
- 未承诺最高充值额、单日限额、零手续费或精确到账时间。
