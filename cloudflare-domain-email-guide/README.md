# Cloudflare 域名购买与免费邮件转发教程

入口：`index.html`。保持 `guide.css`、`guide.js` 和 `assets/` 的相对位置，可直接用现代浏览器打开。字体优先从 Google Fonts 加载；断网时回退到系统衬线和无衬线字体，正文与本地截图仍可阅读。

## 内容

- Registrar：搜索域名、比较注册与续费价格、核对订单、完整注册人字段说明、联系人验证和续费检查。
- Email Routing：接入域名、核对 MX / SPF / DKIM、目的邮箱验证、创建规则与测试收信。
- 发信方案：区分免费收信转发、完整邮箱服务与当前 Email Sending Beta。
- 阅读辅助：目录定位、8 张 PNG 截图的适应窗口 / 100% 原始像素查看、打开原图和下载、地址填写示例、复制、保存于本浏览器的完成清单、可展开问答、打印样式。

内容及截图核验日期：2026-09-09。官方资料链接附在教程对应段落。

本教程展示的 .com 购买流程没有身份证上传或人脸核验步骤；这与联系人填写、邮箱验证是不同环节。根据官方文档，仍要求完整准确的注册联系人资料，WHOIS 隐私处理不等于匿名注册。
